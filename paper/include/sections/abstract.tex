\begin{abstract}
We present a computational substrate in which data, execution, and storage are unified into a single discrete representation. Rather than separating memory, program logic, and inference into distinct components, the system encodes all three within a shared value space and executes by navigating this space directly.

Each unit of information is represented as a fixed-width binary value and stored within a structured memory substrate indexed by spatial coordinates. Computation proceeds not by applying learned parameters or explicit control flow, but by composing transformations over these stored values and resolving queries through global search primitives.

Generation is framed as a constraint resolution process: given partial structure, the system retrieves or synthesizes continuations by traversing the value space and composing existing transformations. New execution patterns discovered during this process are captured and reused, enabling a form of self-extending behavior without gradient-based training.

The system operates entirely through deterministic, hardware-native operations and produces reproducible outputs across modalities. We demonstrate its behavior across multiple experimental domains and describe a pipeline in which the system generates both results and the corresponding research artifact automatically.

This work explores an alternative to parameterized models, where computation emerges from the organization of memory rather than from learned weights.
\end{abstract}
