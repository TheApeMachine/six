\section{Introduction}

Most computational systems enforce a strict separation between three
concerns: memory stores data, programs specify how data is transformed, and
learning mechanisms adjust parameters to improve the transformations over
time.  This division is foundational in both classical software engineering
and modern machine learning, where data resides in tensors, programs are
defined by network architectures, and learning is driven by gradient
descent over differentiable loss surfaces.

This work explores an alternative formulation in which these distinctions
are collapsed.  We describe a system where data, programs, and execution
state share a single binary representation: a fixed-width frame of 1024
bytes.  Each frame carries token data, general-purpose registers, a program
counter, and an embedded program composed from the sixteen two-input boolean
truth tables.  Computation consists of applying these operations across
designated regions of one or more frames, with the result written back into
the same representation.  Because programs are stored within frames, there
is no boundary between the instruction stream and the data it operates on;
a frame may serve as passive storage, an executable program, or both
simultaneously.

Frames interact inside concurrent mixing pools called Regions.  A Region
accepts frames through a multi-tier buffering mechanism and returns them in
non-deterministic order, so that computation emerges from the pattern of
interactions rather than from a predetermined schedule.  A
hardware-abstraction layer routes the underlying boolean operations to
whichever compute substrate is available---CPU, NVIDIA CUDA, or Apple
Metal---through a unified kernel interface that requires only bitwise
logic, integer comparison, and population count.

The architecture does not employ floating-point arithmetic, gradient-based
optimization, or learned parameters.  Instead, behavior arises from the
composition of elementary boolean functions over structured binary memory.
A firmware system provides a library of pre-compiled programs that can be
loaded into any frame's program region at initialization, giving the system
a repertoire of reusable behaviors---including bootstrapping sequences,
structural transformations, and a self-propagating replication program---
without external training.

We evaluate the system across five experimental domains: text
classification, multi-language code generation, CIFAR-10 image
reconstruction, logical reasoning on the bAbI benchmark, and several text
generation tasks including compositional assembly, out-of-corpus retrieval,
and prose chaining.  The experiments are defined programmatically, executed
within the substrate, and compiled into the present document automatically.

The contributions of this paper are as follows.  First, we define the
architecture: a minimal set of primitives---the frame, the boolean
instruction set, the Region, and the multi-substrate backend---and show how
they compose into a functioning runtime.  Second, we report empirical
results across modalities, providing a baseline characterization of what
gradient-free boolean computation can and cannot achieve.  Third, we
demonstrate a self-documenting experimental pipeline in which the system
produces both results and the corresponding research artifact.

This work does not aim to match the performance of large parameterized
models on standard benchmarks.  Its purpose is to explore a different point
in the design space: one where all computation reduces to deterministic,
hardware-native bitwise operations, and where memory is not a passive
container but the medium through which behavior emerges.
